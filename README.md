# Brick Breaker — x86 MASM

A classic **Brick Breaker arcade game** developed in x86 Assembly (MASM) using the Win32 API and Windows GDI.

Built as a Computer Organization and Assembly Language (COAL) project, demonstrating low-level graphics rendering, custom physics, collision detection, and game-state management.

## Features

- Smooth GDI double-buffered rendering.
- Three playable levels with separate high-score tracking.
- Multi-hit bricks with varying durability.
- Random power-ups: Multi-Ball, Extra Life, and Time Reduction.
- Custom ball physics and progressive difficulty.
- Interactive menus, scoring, and gameplay HUD.

## Technologies

- x86 Assembly (MASM)
- Win32 API
- Windows GDI Graphics

## How to Run

1. Install MASM32 SDK or Visual Studio with x86 MASM tools.
2. Open the x86 Developer Command Prompt.
3. Assemble and link the project using the required Win32 libraries.
4. Run the generated executable.

## Controls

| Key | Action |
|---|---|
| Left / Right Arrow | Move paddle |
| Spacebar | Launch ball / Restart |
| Start Game | Begin game |
| Change Level | Switch levels |
| End Game | Return to menu |
